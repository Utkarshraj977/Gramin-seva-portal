# Gramin Seva Portal

A MERN platform that brings essential rural services into one application. It supports separate workflows for service providers, administrators, and users.

## Modules

- Cyber-cafe discovery and service requests
- Doctor and patient workflows
- Teacher and student workflows
- Complaint registration and administration
- Travel and bus-service workflows
- Authentication, profiles, file uploads, email, and real-time chat

## Tech stack

React, Vite, Node.js, Express, MongoDB, Mongoose, Socket.IO, JWT, Cloudinary, Nodemailer

## Run locally

```bash
cd server && npm install
cp .env.example .env
npm run dev

cd ../client && npm install
cp .env.example .env
npm run dev
```
